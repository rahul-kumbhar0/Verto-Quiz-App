# Endings, CTAs and the post package

## One CTA, chosen by goal (last 4–6 s, never before the proof)
| Goal | Spoken CTA pattern | Example |
|---|---|---|
| leads | "Comment **KEYWORD** and I'll DM you <the specific thing>." | "Comment JOBS, and I'll DM you the repo, and exactly how I set it up with Claude." |
| leads (follow gate on) | + "Follow first so the DM reaches you." (spoken only if the reel is ≥ 30 s; else caption only) | |
| sale | free taster by keyword, paid upgrade lives in the DM/guide, never in the reel | "Comment RESUME for the free version." |
| reach | easy comment question with a one-word answer | "Which step surprised you? Drop the number." / "Yes or no in the comments." |
| reach | save for a specific future moment | "Save this for your next placement interview." |
| reach | share to a specific person | "Send this to the friend who still applies on Naukri at 2 am." |
| follow | series promise | "Part 2 tomorrow: what an MCP is. Follow so you don't miss it." |

## Keyword rules
- ONE word, CAPS, on-topic, easy to type on a phone: JOBS, AGENT, SALARY, REFER, RESUME, TOOLS.
  Avoid words people type anyway ("yes", "nice") and words with common typos.
- Same keyword in: spoken CTA, end-frame text, caption line 1, pinned comment, DM automation
  trigger (DirectApply `keywords`, include the singular/plural: job/jobs).
- Say exactly what they get ("the repo + my exact Claude setup"), not "more info".
- The DM must deliver in one tap (guide page link) and the guide must deliver what was promised.

## Loop endings (replays)
End on a line/visual that flows into the first frame: final line "…and that's how it found three
internships while I watched." → first frame is the sheet filling. Or end on the question the
hook answers. Cut the last 0.3 s of silence so the loop is seamless.

## Honesty line (before the CTA when relevant)
"Not sponsored." · "It's open source." · "You'll need Claude Pro for this." · "The catch: it
never presses submit, you do." One line builds more trust than any adjective.
