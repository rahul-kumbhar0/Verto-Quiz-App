# Beat sheets by archetype (pace 2.6 words/s; times are targets)

Every row needs a line AND a visual. A beat with nothing to show gets cut.
Retention devices to place every ~8 s: an open loop ("but that's not the crazy part"), a pattern
interrupt (theme flip dark↔light, a pull-out, a stamp), a number landing, a question answered.

## A. Demo → keyword (goal: leads) · 25–45 s · our best performer
| Time | Beat | Line pattern | Visual |
|---|---|---|---|
| 0–3 s | Hook (transformation / automated / watch this) | "I automated my entire job search. With one free GitHub repo." | the result mid-action |
| 3–8 s | The input (how simple it is) | "I just type: find me Python internships in Bangalore." | typed prompt |
| 8–20 s | What it does, 3–4 proofs, each with a number | "It goes through three million live jobs… no reposts… ghost jobs? It flags them." | each proof pops on its word |
| 20–28 s | The extra / "best part" (pays off the open loop) | "And when I open one, it fills the form for me." | the wow moment |
| 28–33 s | Name + trust | "It's called freehire. Fully open source." | real logo / repo card |
| last 4–6 s | Keyword CTA | "Comment JOBS and I'll DM you the repo, and exactly how I set it up with Claude." | comment typed → DM arrives |

## B. Curiosity explainer (goal: reach / follow) · 35–60 s
| Time | Beat | Line pattern | Visual |
|---|---|---|---|
| 0–3 s | Paradox / "looks like one, is N" / how-without | "Nobody ever wrote the code that lets ChatGPT write Python." | the object, cinematic |
| 3–6 s | Pivot question | "So how does it do it?" | presenter shrug |
| 6–40 s | Mechanism in 3–5 steps, each: name → plain gloss → worked example → consequence | "First, tokens. The model never sees words…" | exploded view / one hero per step |
| 40–48 s | The twist / second trick | "The weird part? None of it was programmed." | pull-out, lens |
| 48–54 s | Payoff restates hook as the answer | "It just predicts the next word, trillions of times." | recap stack |
| last 4–6 s | Question or save CTA (or keyword if there's a freebie) | "Which step surprised you? Drop the number." | comment card |

## C. Resource list → keyword (goal: leads) · 25–40 s
| Time | Beat | Line pattern | Visual |
|---|---|---|---|
| 0–3 s | Count + stakes + brand | "5 free Claude plugins every student should install." | the count in the box |
| 3–30 s | Items: name → what it does for YOU in one line → proof | "First, X. It does Y, so you never Z." | real logo per item |
| 30–34 s | Best one held for last ("and finally…") | | |
| last 4–6 s | Keyword for the links | "Comment TOOLS and I'll DM you all five links." | |
Max 5 items spoken (list more in the DM/guide). Each item ≤ 2 sentences.

## D. News → what it means for you (goal: reach) · 25–45 s
0–3 s "OpenAI just gave its agents their own computer." → 3–10 s what happened, sourced
(outlet + date on screen) → 10–30 s what it means for the viewer (job, money, skill) → 30–38 s
what to do now → CTA (keyword for a guide, or question). Post within 72 h of the news.

## E. Myth-buster (goal: follow / leads) · 30–50 s
0–3 s state the myth as a myth ("Bots don't reject your resume.") → 3–8 s why people believe it →
8–30 s what actually happens, with a source and a number → 30–40 s the fix (2–3 steps) → CTA
(keyword for the template/checklist).

## F. Result story (goal: leads) · 25–40 s
0–3 s the result in numbers ("10 days. 3 offers.") → 3–8 s the one thing that did it → 8–28 s the
exact method (copy-paste message / prompt shown on screen) → 28–34 s why it works (one line) →
CTA ("Comment NOTE and I'll send it as copy-paste"). Results must be real and attributable.

## Spine checklist (all archetypes)
- [ ] Value by second 5; something new every 2–3 s
- [ ] One open loop planted before 10 s and paid off before the CTA
- [ ] ≥ 3 exact numbers with units, each sourced in facts.md
- [ ] Every jargon word glossed in ≤ 6 plain words
- [ ] Payoff line restates the hook as an answer
- [ ] Proof shown before the ask; ONE CTA
- [ ] Total within the goal's length band
