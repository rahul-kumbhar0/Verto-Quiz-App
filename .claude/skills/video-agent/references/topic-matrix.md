# Topic → technique matrix

Classify the topic into a PRIMARY archetype (what the video mostly is) and a SECONDARY
(borrow 1–2 beats from it). Every archetype maps to proven reference reels and a concrete
technique set from the component library.

## A — Software / service / architecture
*"How Supabase/Vercel/UPI/Google Maps/a compiler works", APIs, cloud, apps, protocols*

- **Look**: dark + one brand accent color; light-mode beats for "normal life" moments.
- **Techniques**: `PipelineBar` with stage names + LIVE COUNTER persisting across beats
  (the scoreboard device), `Wire` diagrams between labeled node cards, terminal/`DataPanel`
  recreations, UI mockups (`PhoneFrame`, editors, dashboards), globe/latency beat,
  GitHub/receipt cards, `Gauge` for speed, `Chip` for tokens/ids/hashes.
- **Structure**: HOOK (counterintuitive claim) → the request begins (pipeline stage 0) →
  one beat per stage (advance the bar!) → scale/stress beat (counter goes crazy) →
  "and that's why X" payoff → CTA.
- **Reference reels**: Supabase (316K), Vercel (145K).

## B — Physical device / hardware / manufacturing
*"How touchscreens/tires/speakers/chargers/cameras are made or work"*

- **Look**: dark studio; gold = the invisible force; photoreal.
- **Techniques**: `Studio3D` turntable (ONE beat: the product, amber rim light),
  cross-section exhibits (stacked layers edge-on + `RGBStrip`), `FieldArcs` for
  fields/energy/heat, `CapsLabel` spec labels (WIRES, GLASS, 350 PSI), `Measure`
  dimension lines, giant `Finger`/hand props, analogy prop beat (one real object),
  `StatCard` ("120 scans a second").
- **Structure**: HOOK (macro close-up + claim) → zoom into the hidden layer → explode/
  cross-section → the invisible force visualized (gold) → numbers beat → origin/authority
  (patent, engineer) → bonus trick → CTA.
- **Reference reels**: touchscreen (17.6M), tires.

## C — Everyday-tech mystery / invisible process
*"Why autocorrect/WiFi passwords/cookies/Bluetooth pairing behave like that"*

- **Look**: pixel-faithful UI recreations doing impossible things; amber touch-zones.
- **Techniques**: `Keyboard`/`PhoneFrame`/OS-UI recreations, `ExplodedLayers`
  (what you see / what's underneath), zone overlays that morph, live typing demos,
  `DataPanel` with real-looking data, `Callout` + honesty `Footnote`s, DM-thread CTA.
- **Structure**: HOOK → "so how does it know?" → explode the UI → mechanism with real
  data → edge case/escalation → history/authority → bonus trick → send-this-to CTA.
- **Reference reels**: keyboard (DeZ-ddqMWFE), battery, wifi-password-reel (ours).

## D — Data / scale / money / comparison
*"How much X earns, how fast Y is, X vs Y, what 1 second of internet looks like"*

- **Look**: numbers ARE the exhibits; huge mono type.
- **Techniques**: rolling counters (150px mono), `Gauge`, `StatCard` stacks, timelines
  (era chips, one glowing), comparison grids of mini-boards, red "wrong math" reveals,
  bar/queue visualizations, light/dark alternation for rhythm.
- **Structure**: HOOK (one absurd number) → make it concrete (per second/per person) →
  comparison beat → how it's even possible (borrow mechanism beat from A/B/C) →
  escalation (the number gets worse/better) → source receipt → CTA.
- **Reference**: Vercel's 518,027 req/s gauge beat, battery charge graphs.

## E — Story / drama / origin
*"80 devs rebuilt the PS5", "the engineer who made the keyboard", product origin stories*

- **Look**: receipts everywhere — the drama must be documented.
- **Techniques**: GitHub repo/release/README cards, person cards (photo, name, role),
  book/patent/paper exhibits with year chips, timeline with counts growing, gameplay/
  screenshot "footage" cards WITH CREDIT FOOTNOTES, failure-shown-raw beat (glitch,
  crash, red error), mascot holding props.
- **Structure**: HOOK (the impossible thing happened) → who/why → first attempt fails
  (show the crash honestly) → the breakthrough mechanism → the receipts (repos, releases,
  dates) → where it stands today → CTA.
- **Reference reel**: PS5 emulators (90K likes).

## Mixing rules

- PRIMARY gives the structure + most exhibits; borrow 1–2 beats from SECONDARY.
- Common pairs: A+D (architecture + scale), B+E (device + origin), C+D (mystery + numbers).
- Every video regardless of archetype: karaoke captions with 1–2 `box` words per beat,
  mascot talking in most beats, honesty footnotes, hard cuts, idle motion on every exhibit,
  DM/share CTA in the last beat.
