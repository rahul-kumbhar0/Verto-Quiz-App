# Your own presenter character (PNG mode)

Drop one transparent PNG per pose here (or in `<project>/avatar/`) and set
`avatar: { mode: "png", png: { dir: "avatar" } }` in `index.html`.

File names = pose names: talk explain present point_stage point_up point_side point_cam one two
thumbs fist_pump shrug think pinch stop facepalm hands_head shh wave cross
Optional `<pose>_open.png` (mouth open) enables lip flap. Same framing for all: chest-up, head top
at ~15 % from the top, ≈1200×1280. See `references/avatar.md`.
