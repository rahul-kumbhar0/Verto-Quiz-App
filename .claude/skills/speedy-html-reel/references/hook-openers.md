# Hook openers: the first 1.5 s (demo: `assets/examples/hook-gallery/`, 14 clips on the LinkedIn reel)

Viewers decide in about 0.5–1 s. Each opener below is a built clip in the gallery. Pick ONE per reel
(two at most: a visual opener plus a script hook), state it in the edit plan, and vary it reel to reel.
Never use a slow build from an empty frame.

| # | Opener | How it's built (gallery clip) | Best for |
|---|---|---|---|
| 1 | Topic gag | pain pose (`facepalm` + sweat fx) on the blank tool, then the spark buddy flies in, ring, and the tool fills | "I automated X" |
| 2 | Big reaction + rewind | avatar ×2.3 with the shades-slide gag + "WAIT." in the box, then a VHS rewind back to normal size | shocking result |
| 3 | He grabs the proof | `hold` + paper prop → `point_up` throw; the real UI flies up (spring + echo trail) and lands with shake + ring | any real-UI reel |
| 4 | Recurring sidekick | our own spark buddy (`spark()` svg, not a brand logo) types in the tool; doubles as the honest catch | series identity |
| 5 | Thought bubble pops | dots + cloud with the problem, then pop (burst + rays + grid wave) into the answer cards | relatable pain |
| 7/8/10 | Full frame 0 (HOUSE DEFAULT) | `M.headline` big type on frame 0 over the blurred hero, presenter already in, exits on "here's how" → hero forward (YouTube reel, 3 Nov) | every reel |
| 9 | Start big on the face | avatar ×2.3 `point_cam` + signature flip, springs down to its spot as the UI drops in | "you" hooks |
| 11 | Flash-forward | 0.7 s of the ending (DM + big number), "▶▶ 30 SECONDS LATER", flash, then back to the blank start | funnel reels |
| 12 | Before/after split | two halves split-reveal, a divider draws, the right side odometers | time/money savings |
| 13 | Bright first frame | light chapter + one big `m-acc` block with the contrarian line | stands out in a dark feed |
| 14–18 | Script hooks | payoff word first · open loop · name the audience · contrarian | always write all 4, test 2 |
| 20/22 | Sound hit + freeze frame | impact at t=0; at the gag beat: record scratch, freeze, grayscale, self-roast sticker, scribble round the face | relatable humour |
| 25 | Promise counter | "[3 things]…" + pills fill 1/3, 2/3, #3 locked and shaking | lists |
| 26 | Loop ending | the DM banner morphs back into the opening composer, and the first line returns | replays |

Rules: the gag is about the topic, finished by 1.5 s, one cartoon SFX at most, graphite look kept. Every opener
has the proof on screen by 1.5 s. Use Instagram Trial Reels to test two openers on the same body.
