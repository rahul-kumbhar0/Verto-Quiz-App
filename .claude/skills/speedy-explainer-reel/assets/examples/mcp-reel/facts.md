# Facts (searched 31 Oct 2026; primary pages partly blocked in-session — re-verify on the guide page)
- Zomato: official MCP server, launched 22 Oct 2025: restaurant search, menus, cart, checkout via UPI QR code;
  described as for "testing, experimentation, controlled integrations" (f22labs, Mar 2026). Add as custom connector.
- Swiggy: official MCP servers Food (/food), Instamart (/im), Dineout (/dineout) at mcp.swiggy.com; launched
  27 Jan 2026; Instamart 40,000+ SKUs; production needs approved access (mcp.swiggy.com/access); early
  reports: COD only, partial Instamart (MediaNama Jan 2026).
- Zerodha: official Kite MCP, hosted at mcp.kite.trade, free; reads holdings, positions, orders, P&L, quotes;
  Zerodha describes it as read-only except GTT (third-party review says hosted tool list includes order tools).
- Government: MoSPI (National Statistics Office) MCP server on eSankhyiki, beta, launched 6 Feb 2026,
  mcp.mospi.gov.in, no login; official national statistics (7–21 datasets depending on source).
- Gmail: Claude's official Google Workspace connectors (Gmail, Calendar, Drive): search/read + create drafts,
  does not send; plan availability differs across sources → "check your plan" on the guide page.
- MCP = Model Context Protocol, open standard (Anthropic, Nov 2024) for connecting AI to apps/tools.
