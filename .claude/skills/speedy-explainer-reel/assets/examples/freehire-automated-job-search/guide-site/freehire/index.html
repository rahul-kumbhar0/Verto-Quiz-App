STEP 01

What freehire is

freehire is an open-source job search engine. Instead of copying jobs from other portals, it pulls them straight from company career pages, from Workday, Greenhouse, Lever and 100+ other hiring systems.

🔁
No reposts. The same job posted on three sites shows up once.
🔗
No middlemen. Every listing links to the company's own page.
👻
Ghost jobs flagged. It marks postings that probably aren't really hiring.
🆓
Free to search, no sign-up needed. MIT-licensed, so you can even run your own copy.
⭐ Open the repo on GitHub 🔎 Search jobs on freehire.me
STEP 02

Connect it to Claude

This is the part that makes it feel automated: once connected, you just ask Claude for jobs in plain English. Pick the option for the app you use.

Option A · Claude app or claude.ai EASIEST

  1. Open Settings → Connectors.
  2. Tap Add custom connector.
  3. Paste this URL and save:
https://freehire.me/api/v1/mcp

No account or key needed. This gives Claude the job search tools.

Option B · Claude Code DEVS

Run this inside Claude Code:

/plugin install freehire --marketplace strelov1/freehire-mcp

Option C · Full version SAVE · TRACK · CV

Lets Claude also save jobs, track your applications and tailor your CV to a job.

  1. Create a free account on freehire.me.
  2. Open the account menu → API keys and create a key (it starts with fhk_).
  3. In Claude Desktop go to Settings → Developer → Edit config and add:
{ "mcpServers": { "freehire": { "command": "npx", "args": ["-y", "freehire-mcp"], "env": { "FREEHIRE_TOKEN": "fhk_your_key_here" } } } }

🔒 Your key is like a password. Never paste it in comments, DMs or screenshots.

STEP 03

My 3 prompts (copy-paste)

1 · Find jobs

Find Python or data internships in Bangalore or remote in India. Use the facets tool first so the filters are valid. Show me the 10 newest with company, location, link and one line on why each fits a fresher.

2 · What to learn next

My skills are Python, SQL and Git. Use market_fit to check them against live internship demand in India and tell me the ONE skill that would unlock the most new matches.

3 · Before you apply

Read this job: [paste link]. List what it asks for that I don't have yet, and suggest 3 resume bullet points using only my real projects below. Don't invent anything. My projects: [paste your projects]

Swap in your own skills, city and role. Prompt 2 needs the connector from Step 02.

STEP 04

Daily alerts on Telegram

  1. On freehire.me, run your search (for example Python · Internship · Bangalore).
  2. Save the search (needs a free account).
  3. Turn on the digest for Telegram (or email).

Now new matches come to you every day. You stop searching; the jobs come to you.

STEP 05

Let it fill the application form

  1. Install the freehire extension from the Chrome Web Store.
  2. Open any job's application page and open the freehire side panel.
  3. Click Fill this form.

✋ Always read every field before you hit submit. The extension fills the form; you stay in control.

STEP 06

Good to know

💸
Is it free? Searching is free and needs no sign-up. Some extra AI features (like CV tailoring) can use AI credits.
🇮🇳
Does it have Indian jobs? Yes: about 41,000 jobs in India were posted in the last 30 days (freehire data, 25 Oct 2026). It focuses on IT/tech roles.
⚠️
Never pay to apply. A real job never asks for a fee. If a company asks for money, walk away.
🤝
Not sponsored. freehire is built by Ilya Strelov and the open-source community. If it helps you, give the repo a ⭐.
