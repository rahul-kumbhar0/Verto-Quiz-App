Claude watches the video. Then keeps it as a skill.

Watch is a free, open-source plugin (MIT) that gives Claude Code a video as timestamped frames plus a transcript. After it has watched, you ask Claude to write what it learned into a skill file, and it can use those steps every time. Here are the install steps, the exact prompt, and the catch.

STEP 01

Install Watch

The repo is github.com/bradautomates/claude-video. In the Claude desktop app:

  1. Click Customize in the sidebar, then Plugins.
  2. Open Add, choose Add marketplace, then Add from a repository.
  3. Paste the address below and click Sync.
  4. Find Watch in the list and install it.
  5. Start a Code session.
https://github.com/bradautomates/claude-video

If you use Claude Code in a terminal, type these two lines inside Claude Code instead:

/plugin marketplace add bradautomates/claude-video
/plugin install watch@claude-video

Watch needs Python 3.10+, FFmpeg and yt-dlp on your computer. Ask Claude "check the watch skill's dependencies and help me install what's missing".

STEP 02

Watch your first video

Paste a link and say what you want from it:

Use the watch skill on this video: [paste the YouTube link]. Give me the main steps it teaches, with timestamps.

The first run asks two setup questions. Choose balanced detail and captions only to start. You get a summary with timestamps, built from the video's frames and its captions.

STEP 03

Turn it into a skill

This is a prompt, not a button. After Claude has watched the video, paste:

Turn what this video teaches into a reusable skill. Write a SKILL.md with a clear name, a one-line description of when to use it, and numbered steps in plain words. Save it in my skills folder, then show me the file so I can check it.

Claude writes one file with the steps. Next time you ask for that kind of work, it follows them.

STEP 04

Ideas for students and freshers

📄
A resume tutorial becomes a resume skill that checks your resume the same way every time.
📊
An Excel or SQL video becomes a skill that explains formulas the way that teacher does.
🎤
An interview-prep video becomes a mock-interview skill with that format of questions.
📚
Your own class recording becomes revision notes with timestamps.
THE CATCH

Read this before you try

💻
It works in Claude Code only. The plugin's own README says it does not work in the normal Claude chat or in Cowork. Claude Code needs a paid Claude plan.
⚠️
Claude learns the video's mistakes too. A skill copies what the video says, right or wrong. Open the file and read every step.
☁️
The Gemini option sends the video to Google. It is faster and uses a free Google key, but pick the local option for anything private.
©️
Learn from videos, don't repackage them. Don't turn a paid course into a skill and share or sell it.
