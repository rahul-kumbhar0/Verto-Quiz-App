5 free apps that plug into Claude.

On its own, Claude can't see your files or your apps. A connector links one app to Claude, so it can read from it and do things in it when you ask. Here are five a student can use today, the setup steps, a first prompt for each, and the catch. We use two of them (GitHub and Vercel) to make this page.

How to add any connector

  1. Open Claude (claude.ai or the app) and go to Settings → Connectors.
  2. Find the app in the list and press Connect.
  3. Sign in to that app and read the permission screen before you press Allow.
  4. Back in a chat, open the tools menu under the message box and switch the connector on.

Menu names move around between app versions. If you don't see "Connectors", look for "Integrations" or the tools icon under the message box.

CONNECTOR 01

Google Drive

Claude can search your Drive and read your Docs and PDFs, then answer from them and tell you which file it used.

Search my Drive for my Operating Systems notes. Make a one-page revision sheet from them and tell me which file each point came from.
CONNECTOR 02

Notion

Claude can find any page in your workspace and write new pages for you.

Find my "Placement prep" page in Notion. Then create a new page called "Interview prep plan" with a 2-week checklist based on it.
CONNECTOR 03

Canva

Describe a design in a sentence and Claude makes it in your Canva account, where you can open and edit it. It works with a free Canva account; brand templates need paid Canva.

Make a one-page resume in Canva for a final-year CS student with 2 projects and 1 internship. Clean, one accent colour. Give me the link to edit it.
CONNECTOR 04

GitHub

Claude can read your repositories and help you save work to them. Every reel on our page (script, code, final video) is saved to GitHub this way.

Read the README of my project repo and rewrite it for a recruiter: what it does, how to run it, 3 screenshots to add.
CONNECTOR 05

Vercel

Vercel hosts websites, with a free Hobby plan. With the connector, Claude can put a page live and check that it loads. This page was deployed that way.

Deploy this folder to my Vercel project as a new production deployment, then open the live URL and confirm the page loads.
THE CATCH

Read this before you connect anything

⏳
Free plans have limits. Free Claude has a message limit, and a long task with a connector can use it up quickly. Each app's own free plan has limits too.
🔐
A connector sees what you allow. The permission screen lists exactly what Claude can read and change. If it says "all files", it means all files.
📋
The list changes. Which connectors are on which plan is set by Anthropic and changes over time. Check the plan note next to each connector in the app.
🧹
You can disconnect. Remove a connector in Settings → Connectors, and remove Claude's access inside the app's own security settings.
