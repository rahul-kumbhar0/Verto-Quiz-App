What an AI agent is, plus 3 setups to try this week.

An agent is AI that uses tools, in a loop, until a goal is done. A chatbot answers once and stops. An agent keeps going: think, act, observe, repeat.

STEP 01

The loop, simply

💭
Think. The AI decides what to do next to reach your goal.
⚡
Act. It uses a tool: search the web, open a page, run code, write to a sheet.
👀
Observe. It reads what the tool returned.
🔁
Repeat. It loops until the goal is done (or it asks you for help).

🔒 Safety first: never give an agent your passwords, OTPs or payment details, and review what it does before it submits or sends anything.

SETUP 1

A job-hunt agent (5 minutes)

Connect Claude to freehire, an open-source search over 3.3M+ live jobs from company career pages.

  1. In Claude open Settings → Connectors → Add custom connector.
  2. Paste this URL and save:
https://freehire.me/api/v1/mcp

Then give it a goal, not a question:

Goal: find 10 fresher-friendly Python or data internships in India (remote or Bangalore) posted recently. Use the facets tool first so your filters are valid, search, open the most relevant postings, and give me a table with company, role, location, link and one line on why each fits. Keep going until you have 10 good ones.

Full freehire setup: canwe-guides.vercel.app/freehire

SETUP 2

A research agent (no setup)

Use any AI app that can browse the web (Claude, ChatGPT or Gemini with web search on) and give it a multi-step goal:

Goal: compare the fresher hiring process at TCS, Infosys and Wipro for 2026. Search the web, open the official careers pages first, then news reports. For each company list the tests, rounds, eligibility and approximate packages, with a source link for every number. Flag anything you couldn't confirm.

That "keep going, open sources, flag what you couldn't confirm" instruction is what turns a chatbot answer into agent-style work.

SETUP 3

A coding agent (for devs)

Coding agents like Claude Code read your project, run commands, see the errors and fix them in a loop. Try it on a small project:

Goal: add a "/health" endpoint to this project that returns {"status":"ok"}, write a test for it, run the tests, and keep fixing until they pass. Explain each change before you make it.

💡 Use git and commit before you start, so you can undo anything the agent changes.
