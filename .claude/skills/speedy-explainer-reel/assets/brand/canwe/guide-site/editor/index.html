STEP 01

The Claude desktop app + one prompt for your folders

Install the Claude desktop app, make an empty folder (for example video-editor) and open it in Claude's coding side. Then ask for a workspace. Something like:

Set up a video editing workspace in this folder: clips, references, style, music, exports, and a CLAUDE.md with the rules for how you edit.
STEP 02

One prompt installs five free tools

✂️
FFmpeg cuts, joins and exports the video.
💬
Whisper turns your speech into text, so you get word-timed captions.
📥
yt-dlp downloads reference reels so Claude can study them.
🎬
Remotion and HyperFrames make motion graphics with code: titles, callouts, animated text.
Install FFmpeg, yt-dlp, Whisper, Remotion and HyperFrames for this workspace. Check each one works and tell me what you installed.

Installs take about 10–15 minutes. Read what Claude wants to run before you approve it.

STEP 03

The watch skill: teach it a style

The watch skill (from his description) lets Claude study a reference reel and save what it learns, such as caption style, cut speed, music and sound, into your style folder. Next time you edit, it uses that file.

Get the skill file from his video's description, open it and read it before you add it.

STEP 04

Your first edit

Drop your clip into clips and type what you want in plain English:

Edit clips/take1.mp4 in my saved style: cut the silences and filler words, add word-by-word captions with one keyword highlighted, add soft background music, export a 9:16 reel to exports/.

Watch the result, then tell it what to fix like you'd tell a human editor: "the captions are too low", "cut faster in the first 3 seconds".

THE CATCH

What nobody says in the viral reels

🐢
It renders on your laptop. A slow laptop means a slow edit. A 40-second reel with motion graphics can take several minutes.
©️
Only feed it clips you're allowed to use. Study other people's reels for style, don't re-upload their footage or music.
💳
It runs through Claude's coding side (Claude Code in the desktop app), which needs a paid Claude plan. The tools themselves are free.
👀
It's a first cut, not a finished film. You still watch it and fix what looks off. The "14 minutes" in the tutorial is one creator's result.
