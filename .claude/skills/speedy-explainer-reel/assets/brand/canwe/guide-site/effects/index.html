A creator called Vibha Ramprakash (@vibha.in.progress) put 51 video effects into a free Claude Code skill. You drop your video in, type /effects and the name of an effect, and Claude renders it. Here's the install line, how to use it, all 51 names, and the catch.

STEP 01

Install (one line)

The repo is github.com/Vibha-Ramprakash/claude-video-effects. Open a terminal and paste:

git clone https://github.com/Vibha-Ramprakash/claude-video-effects ~/.claude/skills/effects

Then restart Claude Code. Or let Claude do it. Paste this into Claude Code:

Install the skill from github.com/Vibha-Ramprakash/claude-video-effects into ~/.claude/skills/effects

The first run sets itself up in about 2 minutes. It needs ffmpeg and Python and installs them if they're missing. Read what it wants to run before you approve.

STEP 02

Use it

  1. Open Claude Code and drag your video into the chat.
  2. Type /effects, the effect's name, and when you want it.
  3. Claude renders yourvideo_effects.mp4 next to your original. Your audio stays as it was.
/effects orbit from 3 to 6 seconds
/effects spotlight when I say "kill the lights"
Add locked-on from 6 to 10s, then orbit from 10 to 13s, then a reject stamp on "no".

You can say the timing in plain words, and stack several effects in one message. If something looks wrong ("the word covers my face"), tell Claude and it renders again.

THE CATCH

What to know before you try

🧪
These are starter versions. Her own notes say they won't match the exact edit in her reels. The full set (220+ effects) is in her paid studio.
🔇
No sound, no captions. The skill adds neither. Add them in your editor afterwards.
💳
Claude Code needs a paid Claude plan (or API credits). The skill itself is free.
📄
No standard licence in the repo. Use it for your own videos; don't re-upload or resell the skill.
🎬
The effects in our reel are our own recreations on our cartoon presenter, not the tool's output. Hers follow a real face.
