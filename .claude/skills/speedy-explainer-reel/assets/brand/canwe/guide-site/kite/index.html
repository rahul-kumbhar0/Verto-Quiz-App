STEP 01

Add Zerodha's Kite MCP to Claude

It's hosted by Zerodha at mcp.kite.trade: no install, no API key. Source: github.com/zerodha/kite-mcp-server (MIT licence).

claude.ai or the Claude app: Settings → Connectors → Add custom connector → paste this URL → Add:

https://mcp.kite.trade/mcp

Claude Desktop (config file): Settings → Developer → Edit config, add this inside mcpServers, save, restart Claude. Needs Node.js installed.

"kite": { "command": "npx", "args": ["mcp-remote", "https://mcp.kite.trade/mcp"] }

Claude Code (one command):

claude mcp add --transport http kite https://mcp.kite.trade/mcp
STEP 02

Log in to Kite (from inside Claude)

  • 1
    Type: "Log in to Kite." Claude replies with a login link.
  • 2
    Open the link and log in on Zerodha's own page (kite.zerodha.com). Never type your password or TOTP into the chat.
  • 3
    Come back and type: "Show my holdings." If you see them, you're connected.
  • 4
    The login expires (Kite sessions don't last forever, usually a day). If Claude says you're logged out, just repeat step 1.
STEP 03

Paste the rule first (every new chat)

This is the "explain · never advise" rule from the reel. It's a prompt rule you type, not a Zerodha setting, so paste it at the start of each chat (or put it in a Claude Project's instructions).

RULES for this chat: You are my portfolio explainer, not an advisor. Use my Kite data to explain facts and numbers in simple English. NEVER tell me to buy, sell or hold anything, never predict prices, and NEVER place, modify or cancel any order or GTT. If I ask for advice, remind me you only explain. Show the numbers you used.
STEP 04

The 4 prompts from the reel

1 · One-page portfolio report (≈10 seconds)

Using my Kite holdings and mutual fund holdings, make a one-page report: total invested, current value, total gain or loss in ₹ and %, my best and worst holding by % return, and my split by sector / fund type as percentages. A short table, then 3 plain-English lines on what the numbers show. No advice.

2 · Hidden overlap between my funds

List my mutual funds from Kite. For each, look up its latest top 10 holdings from the fund house's official factsheet (say which month). Show which companies appear in more than one of my funds, and each fund's expense ratio. Explain the overlap in simple words. Don't tell me to switch or sell anything.

Kite shows which funds you own, not what's inside them, so Claude needs web search on for this one (or paste the factsheets yourself).

3 · Jargon → English, with my own numbers

Explain these like I'm new to investing, each in 2 lines, using an example from MY portfolio: XIRR, P/E ratio, expense ratio, NAV, LTP, and the difference between unrealised and realised P&L. If you can't calculate one from my data, say so instead of guessing.

4 · My tracker sheet

Make a tracker file (Excel/CSV) of my holdings with columns: Holding, Quantity, Average buy price, Today's price (LTP), Current value, Change %. Sort by current value. Then tell me how to open it in Google Sheets.

Claude makes the file; download it and open it in Google Sheets (File → Import). Re-run the prompt whenever you want fresh prices.

STEP 05

Safety rules (read once)

🧭
Analysis, not advice. Claude isn't a SEBI-registered advisor and neither am I. Use it to understand your numbers; decisions are yours.
🔒
Orders. Zerodha's hosted server leaves out the normal buy/sell order tools, but its GTT (good-till-triggered) tools may be there. The rule prompt says never touch orders; check what Claude did before you approve any tool call.
✋
Approve tool calls yourself. Keep Claude's "ask before using a tool" on for Kite. Read what it wants to call.
🔑
Passwords and TOTP only ever go into Zerodha's own login page, never into a chat.
📅
Check the date on any number Claude looks up (factsheets, prices). Old data = wrong picture.
