STEP 02

Connect trends: what's blowing up this week

We use a Chrome extension (PullRows) connected to Claude: it reads the top reels for a hashtag and ranks them by views per hour, so you copy patterns, not luck. Any trend tool works. The point is to pick topics from real numbers.

Find the 10 fastest-growing reels on #[your niche] from the last 7 days. For each: the hook (first sentence), length, views and comments. Then tell me the 3 patterns the winners share and ONE topic I can post today.

In the reel: our real scan from 1 Nov 2026. The top format on #claudeai was "Claude made this video" (about 1.8M, 1.3M and 1.0M views, the tool's estimates).

STEP 04

Claude writes every scene as code (HTML), adds the voice (ElevenLabs, uses credits) and renders the reel with Playwright + ffmpeg. No video editor, no timeline. These are the exact skills that made this reel:

🎬
speedy-explainer-reel: the cartoon presenter, kinetic captions, motion graphics, real product UI, 14 hook openers, and the render / voice / music / mix scripts. Plus 3 presets.
⬇️ Download the skills (zip, 1.8 MB)

Install: unzip into ~/.claude/skills/, open Claude Code and say:

Use reel-script-writer to write a 40-second reel about [topic] for [audience]. Then build it with speedy-explainer-reel and render a preview.

Needs Claude Code, Node + Playwright (Chromium), Python 3 and ffmpeg. Some files mention our own setup (voice, guide site, DM tool), so swap in yours. Licences are in the zip's README (parts adapted from HyperFrames, Apache-2.0; fonts OFL; Octicons MIT).
