Claude Code for free. The brain isn't Claude.

Free Claude Code is an open-source tool (68,932 ★ on GitHub, 12 Nov 2026) that runs on your laptop. You open the normal Claude Code app, and the tool sends your requests to a free AI model instead of Claude. Here's the setup, which free key to get, and what to keep off it.

STEP 01

How it works (10 seconds)

💻
The app: Claude Code (or Codex, Cline, OpenCode and 8 more coding apps).
🔀
The middle: Free Claude Code, running on your laptop. It catches every request the app sends.
🧠
The brain: a model from the provider you pick, like NVIDIA, Google or Groq, on their free tier. Not Claude.
STEP 02

Install it (check the script first)

Mac / Linux. The install is one line that downloads a script and runs it. Before running anything like that, look at what it does. This one has a dry run that only prints its commands:

curl -fsSL "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.sh" | sh -s -- --dry-run

Happy with it? Run it for real:

curl -fsSL "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.sh" | sh

Windows (PowerShell):

& ([scriptblock]::Create((irm "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.ps1")))

It installs uv (a Python tool manager), then asks which coding apps you want. Pick only Claude Code if that's all you use; it comes from Anthropic's own installer.

STEP 03

Get a free key (the settings)

  • 1
    Start it. Windows / Mac: open Free Claude Code from your apps. Linux: run fcc-server and keep that terminal open. The Admin page opens.
  • 2
    Default (the project's own pick): NVIDIA. Make a key at build.nvidia.com/settings/api-keys. In Admin → Providers → NVIDIA NIM → Add key → paste → Save. Leave the model on the default (nvidia/nemotron-3-ultra-550b-a55b) → Apply.
  • 3
    Backups: a Google AI Studio key (aistudio.google.com/apikey) or a Groq key (console.groq.com/keys), added the same way. Turn on fallback so it switches when one runs out.
  • 4
    Optional: in Admin, turn on Proxy Authentication so nothing else on your network can use your proxy.
STEP 04

Open Claude Code like normal

VS Code: install the Claude Code extension, then in Admin → Integrations → Connect on its card, and reload VS Code. In the terminal, use the launcher the installer added. Same commands as always. Your answers now come from the free model.

To go back to real Claude, click Disconnect on the same card.

STEP 05

The catches

🧠
It's not Claude. Free models are good for practice and small fixes. On long, hard tasks they're weaker. For your hardest work, real Claude is still better.
🏢
Your code goes to the provider you pick. Read their data rules, because free tiers may keep or use what you send. Never put company or client code through it. Practice projects only.
⏳
Free limits belong to the providers. They can shrink or end any time. The tool's "1.3 billion free tokens a month" is a total across providers, not a promise.
📄
Not from Anthropic. It's an independent open-source project (AGPL licence).
