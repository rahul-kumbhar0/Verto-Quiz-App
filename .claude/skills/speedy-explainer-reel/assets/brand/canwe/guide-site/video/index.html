STEP 01

The idea: let Claude find the pattern

Open the 5 best reels in your niche from the last 2 weeks. Copy each one's hook (first line), caption, length and view count. Paste them into Claude with:

Here are 5 top reels from my niche (hook, caption, length, views). Find the pattern they share: hook type, length, structure, CTA. Then give me 5 reel ideas for MY page that use the same pattern but a topic they didn't cover. My niche: [your niche]. My audience: [who].
STEP 02

The script: hook first, under 45 seconds

Write a 35–45 second reel script on [idea]. Rules: the first line is a hook of 6 words or fewer with a number or a strong claim; one idea per line; spoken, casual, like telling a friend; prove it before you ask; end with ONE call to action ("Comment WORD and I'll DM you…"). Give me 5 hook options scored 0–10 first, then the script with the best one. Max 125 words.

Read it out loud once. If you run out of breath in a sentence, cut it in two.

STEP 03

The voice

🎙️
ElevenLabs (what we use): paste the script, pick a voice, download the MP3. It uses credits (a 40-second reel costs us ~750–850 credits on the v3 model).
💻
Free, on your laptop: a local text-to-speech voice (for example Kokoro, open source). Less expressive, costs nothing. Or record your own voice on your phone: still the most human option.
STEP 04

The video: HyperFrames in Claude Code

HyperFrames by HeyGen turns HTML into MP4 video and ships skills that teach Claude how to use it. Core tool: free and open source (Apache-2.0). Needs Node.js 22+, FFmpeg and Claude Code.

1. Create the project (this also installs the HyperFrames skills into Claude Code):

npx hyperframes init my-reel --resolution portrait

2. Open it in Claude Code (start a new session so the skills load):

cd my-reel && claude

3. Describe your reel:

Using /hyperframes, make a 9:16 reel (1080×1920) from this script and my voiceover file (voice.mp3 in assets/): [paste script]. Big bold captions word by word, one visual per sentence, my brand colours [#hex], a strong first frame that works on mute. Keep text between 170 px and 1330 px from the top so Instagram's buttons don't cover it. Run the check before you show me.

4. Check and render:

npx hyperframes check npx hyperframes render -o reel.mp4

Our test: an 8-second 1080×1920 clip rendered in 9 seconds (v0.9.15). Two things we hit: the check flagged an empty first frame (fix it, it's your thumbnail), and the render couldn't load an animation library from the internet in our sandbox, so we put a local copy in assets/.

STEP 05

Captions, cover, and you post it

Write my Instagram caption for this reel: first line = the hook or "Comment WORD…", then 3–5 short value lines, one honest line, a [keywords: …] line with 5 search phrases, and 4 hashtags. Then give me 3 cover texts of 5 words or fewer.
  • 1
    Cover: ask Claude for a 1080×1920 cover frame in the same project, with the key text inside the middle 3:4 area (that's what your profile grid shows).
  • 2
    Post it yourself. Watch the whole reel once with sound and once on mute before you press Share.
THE CATCH

What it costs, honestly

💳
Claude Code needs a paid Claude plan. HyperFrames itself is free.
⭐
HyperFrames has a paid Pro tier (extra style templates and features). Everything in this guide uses the free, open-source core.
🧪
Your first reel takes practice: expect an hour and a few rounds of "make the captions bigger". It gets fast after that.
🔐
Skills run with your agent's permissions. The installer says it too: read what you install.
