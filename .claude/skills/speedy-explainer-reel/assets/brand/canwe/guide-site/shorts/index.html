One long video in. A stack of Shorts out.

AutoShorts is a free GitHub repo (a desktop app you install). You drop in a long video, it writes a transcript, an AI picks the moments worth posting, and it cuts them into vertical 9:16 Shorts with captions. Here's the safe setup, the settings, the real cost and the catches.

STEP 01

Download it from the Releases page only

Open the repo's own Releases page and pick the file for your computer: .dmg on Mac (Apple Silicon or Intel), .msi / .exe on Windows, .deb / .AppImage on Linux.

https://github.com/JayWebtech/autoshorts/releases

The installer isn't signed, so your computer will warn you (macOS Gatekeeper, Windows SmartScreen). That warning is why the source matters: never install a copy from a Drive link, a Telegram file or a "mod" site.

STEP 02

Install FFmpeg (it does the cutting)

Mac (with Homebrew):

brew install ffmpeg

Windows:

winget install ffmpeg

Linux (Ubuntu/Debian):

sudo apt install ffmpeg
STEP 03

Add your API keys (the settings I'd use)

🎙️
Transcription: Deepgram key. Writes down every word with timestamps.
🧠
Picking the moments: Claude or DeepSeek. The repo's README puts Claude at about $0.01–0.05 per video and DeepSeek at under $0.001. Claude for better picks, DeepSeek for the cheapest.
💻
Fully offline mode (Ollama + local Whisper) is free, but the README itself says small local models are generally not good at finding viral moments. Use it only to test.

Whichever cloud you pick gets your transcript. Don't run private or client videos through it without permission.

STEP 04

Make your Shorts

  • 1
    Import one long video (a podcast, a talk, a tutorial). Talking videos work best.
  • 2
    Let it transcribe and rank the moments. The ranking is an AI guess, not a promise: watch each clip before you post it.
  • 3
    Export the 9:16 clips with captions. Check the captions for wrong words, names and numbers.
STEP 05

Upload as private, then press publish yourself

If you set up our YouTube automation from part one, have it upload the new Shorts as private. Nothing goes public until you watch it and press publish. Want part one? Read the YouTube guide.

STEP 06

The catches

🎯
It crops the centre. No face tracking, so stay in the middle of your frame when you record (two people side by side will get cut off).
🔐
Unsigned installer. Only from the Releases page above.
📄
No licence on the repo. The code is public and the app is free to use, but that's not the same as "open source", so don't copy its code into your own product.
💸
"Free" = free app. Good results need the small API cost above.
